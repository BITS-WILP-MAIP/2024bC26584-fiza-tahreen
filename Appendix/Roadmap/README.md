# Roadmap

The four-phase roadmap with its gates lives in **[`../PRD/PM_Artifact_Pack.md`](../PRD/PM_Artifact_Pack.md)** §9, and in condensed form in `02_Final_Report.md` §3.5.

| Phase | Proves | Gate |
|---|---|---|
| 1. Prove the decision | Backtest vs historical seasons. No UI | Beat both baselines by ≥+5% margin recovered, or stop |
| 2. Prove the workflow | Planner MVP in shadow mode; decisions not applied | Planners engage; override reasons substantive |
| 3. Controlled pilot | One category, live, matched control group | Margin vs control; acceptance in band; no unexplained high-confidence failures |
| 4. Widen | More categories and clusters; second retailer | Integration investment starts here, not before |

Launch thresholds per gate: `Appendix/Metrics/Data_Model_Evaluation.md` §7.
Phase count is consistent across the deck, Executive Summary, PM Artifact Pack and Final Report.
