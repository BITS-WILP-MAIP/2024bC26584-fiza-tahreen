# Prototype screenshots

Captured from `ClearSight_Prototype.html`. The prototype itself is interactive, so these are for readers of the PDF submission who are not running it.

| File | Screen |
|---|---|
| `01_worklist.png` | Exit worklist. 184 items ranked by value at stake, confidence per row, 31 routed to manual |
| `02_high_confidence_detail.png` | High-confidence item detail. Recommendation as an action, options compared, sell-through by cluster, plain-language "why", three equal actions |
| `03_low_confidence_abstain.png` | **The abstain state.** No recommendation at all, three reasons why confidence is low, all evidence still shown |
| `04_reason_capture.png` | Reason capture on reject. The override path that makes human-in-the-loop real |

Static wireframes for the screens outside the MVP walkthrough (backtest gate, outcome tracking, cluster configuration) are in `Appendix/Wireframes/`.
